# IPv6 地址管理

一个用于 Linux VPS 的独立交互式 Bash 工具，可在指定网卡上添加、查看和删除附加 IPv6 地址，并在开机时恢复已保存的地址。

## 运行环境

- Linux 使用 systemd，脚本需要 root 权限。
- 需要 Bash、`ip`、`systemctl` 和 `flock` 等系统工具。
- 需要服务商已将目标 IPv6 地址分配或路由到设备。实际前缀长度和上游网络配置以服务商提供的信息为准。

当前版本尚未在实际 Linux VPS 环境中验证。

## 安装

将 `ipv6-manager.sh` 上传到设备，然后以 root 运行：

```bash
bash ipv6-manager.sh
```

首次进入菜单后选择 **6. 安装**，确认后脚本会安装管理命令和开机服务。安装完成后可通过以下命令进入菜单：

```bash
ipv6-manager
```

菜单中的安装状态根据服务文件判断。执行安装后，选择 **4. 设置网卡**，输入实际网卡名。提示中的默认值是 `eth0`。

## 菜单功能

| 选项 | 功能 |
| --- | --- |
| 1. 查看地址 | 显示本工具管理的地址，以及所选网卡当前的 IPv6 地址。 |
| 2. 添加地址 | 输入一个 IPv6 地址并立即添加，同时保存到开机列表。未输入前缀时默认使用 `/128`。 |
| 3. 删除地址 | 从列表中选择编号，确认后删除地址及其保存记录。 |
| 4. 设置网卡 | 选择用于管理附加地址的网卡。列表中已有地址时，需先删除它们才能更换网卡。 |
| 5. 重新应用 | 按保存的列表检查并添加地址，等待地址完成重复地址检测。 |
| 6. 安装 | 未安装时显示，确认后安装命令和开机服务。 |
| 7. 完全卸载 | 已安装时显示，确认后清理本工具管理的地址、配置、命令和服务。 |
| 0. 退出 | 退出菜单。 |

添加地址示例：

```text
IPv6 地址（不填前缀默认 /128）：2001:db8:1234:5678::101
地址已添加并保存。
```

示例中的地址用于文档说明，请换成实际分配给设备的地址。已存在于网卡上的地址不会通过添加菜单接管。当前没有按序号修改地址的功能，可以先删除旧地址，再添加新地址。

交互终端中，操作结果会保留到按回车返回菜单。支持的终端会刷新页面，并以颜色显示状态。设置 `NO_COLOR` 环境变量可以关闭颜色。

## 开机恢复与检查

安装时会启用 `ipv6-manager.service`。服务在 `networking.service` 之后应用保存的地址，逐个等待地址就绪。若重复地址检测失败或等待超时，服务会报告失败。

```bash
systemctl status ipv6-manager.service --no-pager
journalctl -u ipv6-manager.service -b --no-pager
ip -6 address show dev eth0
```

将 `eth0` 换成实际选择的网卡。地址显示在网卡上后，还应从外部验证它是否可达。地址绑定成功本身不能确认宿主机和上游网络已正确转发流量。

## 文件位置

| 路径 | 用途 |
| --- | --- |
| `/usr/local/sbin/ipv6-manager` | 已安装的管理命令。 |
| `/etc/ipv6-manager/interface` | 保存所选网卡。 |
| `/etc/ipv6-manager/addresses` | 保存由本工具管理的地址列表。 |
| `/etc/systemd/system/ipv6-manager.service` | 开机应用地址的 systemd 服务。 |

## 卸载

运行 `ipv6-manager`，选择 **7. 完全卸载**并确认。脚本会清理它管理的地址及上表中的配置、命令和服务。如果其他服务依赖该开机服务，应先解除依赖。
